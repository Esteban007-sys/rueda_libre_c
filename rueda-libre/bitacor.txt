} 7 - Comprobación de herencia (MiniReto 9)
En DevTools (Styles y Computed):
- Propiedad que se hereda:
  * font-family (y color): El elemento <p> hereda la fuente 'Open Sans', sans-serif y el color var(--color-gris) directamente desde el <body> por cascada/herencia tipográfica natural sin tener que redefinirlo en el selector p.
- Propiedad que NO se hereda:
  * margin (y padding / background-color): Las propiedades del modelo de caja (box model) como margin, padding, border o background-color no son heredables; cada párrafo conserva sus propios márgenes calculados por el navegador o definidos explícitamente en el CSS.

} 8 - Conflicto de cascada y especificidad en la navegación (MiniReto 10)
1. Reglas en conflicto del compañero:
   #menu a { color: var(--gris-asfalto); }
   .activo { color: var(--verde-ruta); font-weight: 600; }

2. Cálculo de especificidad:
   - #menu a:
     * [0] Estilos en línea: 0
     * [a] IDs (#menu): 1
     * [b] Clases, atributos, pseudoclases: 0
     * [c] Elementos (a): 1
     * Puntuación de especificidad: (0, 1, 0, 1) ó 101

   - .activo:
     * [0] Estilos en línea: 0
     * [a] IDs: 0
     * [b] Clases (.activo): 1
     * [c] Elementos: 0
     * Puntuación de especificidad: (0, 0, 1, 0) ó 010

3. Causa del problema:
   El selector '#menu a' contiene un ID (#menu), lo cual le otorga una especificidad de (0, 1, 0, 1). Por las reglas de la cascada CSS, cualquier selector con un ID tiene mayor peso que un selector simple de clase (0, 0, 1, 0), sin importar el orden en que estén escritos en el archivo. Por lo tanto, el color de '#menu a' anula la declaración de '.activo' y DevTools la muestra tachada.

4. Solución aplicada sin !important ni estilos en línea:
   Se aumentó la especificidad del selector del enlace activo combinándolo con el elemento dentro del menú:
   '#menu a.activo' (especificidad: 0, 1, 1, 1 ó 111).
   Al tener un ID, una clase y un elemento, supera a '#menu a' (0, 1, 0, 1) y permite que el enlace de la página activa se pinte en verde (--verde-ruta) con font-weight: 600 correctamente.


} 9 - Medición del Box Model en Tarjeta de Servicios (MiniReto 11)
Medición en DevTools (Computed) del ancho de una tarjeta de servicio con width base (250px), padding horizontal de 1rem (16px a cada lado) y borde de 2px a cada lado:

1. Antes (box-sizing: content-box - comportamiento por defecto):
   - Contenido (Content): 250px
   - Relleno (Padding): 16px + 16px = 32px
   - Borde (Border): 2px + 2px = 4px
   - Ancho Total en Computed: 250px + 32px + 4px = 286px.
   - Observación: El ancho declarado no incluía ni el relleno ni el borde, provocando que las tarjetas fueran más anchas de lo asignado y se apretaran o desbordaran en el contenedor.

2. Después (box-sizing: border-box - regla global aplicada):
   - Ancho Total asignado: 250px
   - Borde (Border): 4px (incluido dentro del ancho)
   - Relleno (Padding): 32px (incluido dentro del ancho)
   - Contenido real (Content): 250px - 32px - 4px = 214px
   - Ancho Total en Computed: Exactamente 250px.
   - Observación: Las tarjetas mantienen su tamaño exacto independientemente del relleno y del borde, logrando una separación simétrica y una cuadrícula fluida sin desbordamientos.

} 10 - Resumen semanal y consolidación v1.0 (MiniReto 12)
Resumen de lo construido durante la semana:
- MiniReto 1: Inspección de protocolos, URLs, puertos, métodos GET y códigos de respuesta HTTP (200 OK) usando Live Server.
- MiniReto 2: Diagnóstico y comprensión de errores 404 (rutas inexistentes).
- MiniReto 3: Definición del rol de cada tecnología web: HTML (estructura), CSS (presentación y estilo), JS (interactividad y lógica).

- MiniReto 5: Estructuración semántica en HTML5 (header, nav, main, section, article, footer) evitando divs innecesarios.

- MiniReto 7 (MR 9): Hoja de estilos externa (styles.css), tipografías Google Fonts (Montserrat 700 y Open Sans 400/600), paleta de colores de marca y comprobación de herencia.
- MiniReto 8 (MR 10): Resolución de conflictos de cascada y especificidad (#menu a vs #menu a.activo), pseudo-clases :hover y :focus con contraste 4.5:1 para accesibilidad total.
- MiniReto 9 (MR 11): Control del espaciado con box-sizing: border-box, escala de espaciado en rem, solo bordes en px, tarjetas con imágenes al 100% y tablas legibles.
